0.4.1 makes `/automode-classifier status` easier to read. `on` and `off` show the same block.

```
Auto mode: OFF for this session   (turn on: /automode-classifier on)
1. Rules:      3 allow (no UI: asks run, prompts: block after 1 minute)
2. Classifier: llamastash/lancet, via Pi (allow < 0.2, next 0.2-0.8, ask >= 0.8)
3. LLM:        llamastash/flash-next-128k, via Pi (two-stage, thinking:medium)

Session:       0 allowed by rule, 0 by model, 0 asked, 0 blocked
Config:        ~/.pi/agent/extensions/pi-automode-classifier/config.json
Log:           ~/.local/state/pi-automode-classifier/decisions.jsonl
```

- One numbered row per step, in the order a command goes through them: your rules, then each decider.
- A classifier shows its score bands: what it allows, what goes to the next decider, and what asks you. The last decider has no middle band.
- Rule counts show only when they are not 0. No rules shows `none`.
- The LLM row shows `asks instead of blocking` or `asks when it has no answer` only when you set `onBlock` or `onNoAnswer` to `ask`.
- A config error is on the second line, not the last.
- Gone: the counts of lines in the chat decider's prompt lists, the transcript limits, and `commands are sent to <provider>`.

Also in this release, the README lists the classifier context keys one setting per line.

```
pi install npm:pi-automode-classifier
```
